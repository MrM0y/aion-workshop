# Відгуки

У програмі натисни **Відгук**, вибери місце й напиши свою пропозицію. Після збереження відкриється GitHub: переглянь нотатку й натисни **Create**. Потрібен звичайний обліковий запис GitHub. Можна також створити Issue безпосередньо в репозиторії й додати скриншот.

Відгук публічний. Програма не надсилає автоматично історію ринку, налаштування, значення полів, зображення екрана чи облікові дані. Автор репозиторію отримує сповіщення про Issues; доставки електронною поштою залежать від його налаштувань GitHub.

Відвідувачам не надається доступ на запис до основного репозиторію. Зміни офіційного коду та релізів робить власник. Публічний GitHub технічно дозволяє створювати власні копії й пропозиції змін; це не змінює офіційну програму.
