# AION Workshop

Допомагає вирішити, що крафтити та які ресурси вигідніше купити в AION 2.

**[Завантажити для Windows 10/11 · x64](https://github.com/MrM0y/aion-workshop/releases/latest/download/AION-Workshop.exe)**

### Що вміє

- **Вигідний крафт:** порівнює рецепти за витратами, можливим прибутком і ризиком, враховує комісії та невдачі.
- **Спорядження:** рахує матеріали й бюджет на шлях до потрібної речі з урахуванням шансів і того, що вже маєш.
- **Дешеві ресурси:** шукає ціни нижче історичного рівня та порівнює купівлю з переробкою, зокрема ефіру.
- **Ринок:** показує історію цін і доступну статистику; читає видимі лоти з вікна гри. Ціни можна виправити вручну.

### Як почати

Завантаж EXE → запусти → вибери сервер → натисни **«Знайти вигідне»**. Налаштування зберігаються, нові версії пропонуються при запуску. Інтерфейс українською, назви предметів — RU/EN. Кнопка **?** допоможе розібратися.

Прибуток залежить від фактичного продажу. Прогноз часу продажу доступний лише за достатньої підтвердженої історії угод.
