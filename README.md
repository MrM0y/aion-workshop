# AION Workshop

Допомагає вирішити, що крафтити та які ресурси вигідніше купити в AION 2.

**[Завантажити Setup для Windows 10/11 · x64](https://github.com/MrM0y/aion-workshop/releases/latest/download/AION-Workshop-Setup.exe)**

### Що вміє

- **Вигідний крафт:** порівнює рецепти за витратами, можливим прибутком і ризиком, враховує комісії та невдачі.
- **Спорядження:** рахує матеріали й бюджет на шлях до потрібної речі з урахуванням шансів і того, що вже маєш.
- **З ефіром:** порівнює витрати й прибуток із прямою купівлею; підбирає суміш готових ресурсів і переробок різних сортів.
- **Дешеві ресурси:** шукає пропозиції нижче історичного рівня.
- **Ринок:** показує історію цін і доступну статистику; автоматично читає видимі лоти при відкритті й прокрутці ринку. Ціни можна виправити вручну.

### Як почати

Завантаж Setup → вибери папку → встанови → запусти з ярлика. Вибери сервер і натисни **«Знайти вигідне»**. Наступні оновлення завантажують лише змінені файли, налаштування зберігаються. Інтерфейс українською, назви предметів — RU/EN. Кнопка **?** допоможе розібратися.

Користувався старим portable EXE? Закрий програму й встанови Setup один раз — це додасть новий оновлювач.

Прибуток залежить від фактичного продажу. Прогноз часу продажу доступний лише за достатньої підтвердженої історії угод.

**Є пропозиція?** Натисни **«Відгук»** у програмі, познач потрібне місце й підтвердь заявку на GitHub.
